# Adeudos Comunidad · Av. de Rafaela Ybarra, 5

PWA para generar las remesas bimestrales de adeudos SEPA de la comunidad de propietarios e importarlas en la banca online del Santander.

- Formatos: XML pain.008.001.02 (CORE y B2B), Cuaderno 19.14 y Cuaderno 19.44.
- Remesas nombradas por bimestre (`NOV-DIC-2026`), cobro siempre el día 10.
- Los datos de deudores (DNI, IBAN) se guardan solo en el dispositivo (localStorage); este repositorio no contiene datos personales.

Uso en iPhone: abrir https://rmartinrosado.github.io/adeudos-rafaela-ybarra/ en Safari → Compartir → Añadir a pantalla de inicio.
